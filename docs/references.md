- [entitymar/MVAVE-ANNBLACKBOX-FIRMWARE-UPDATE-SOFTWARE-decompiled](https://github.com/entitymar/MVAVE-ANNBLACKBOX-FIRMWARE-UPDATE-SOFTWARE-decompiled) – decompiled official updater

## Open firmware on the same platform (installed over USB only)
- [hugelton/Felucca](https://github.com/hugelton/Felucca) – GPL-3.0 FM-1 firmware; macOS toolchain via Docker, loader, web installer, second core — **the base of our port**
- [charlesvestal/fm1-x0x](https://github.com/charlesvestal/fm1-x0x) – Felucca fork with a safe mode
- [genkigenki/fm1-to-smk37](https://github.com/genkigenki/fm1-to-smk37) – FM-1 → SMK-37 port kit (another AC791N board)
- [m-vave/fm1_open](https://github.com/m-vave/fm1_open) – M-VAVE's official open source for the FM-1
- [aroum/fm1-custom-fw](https://github.com/aroum/fm1-custom-fw) – index of firmware and tools
